# Automagically pull the latest FP from the Canary Android Builds

## Ready to be used prop files for PIFork are in 'devices'

Just download a random .prop file from the 'devices' or 'betas' folder and put it in `/data/adb/modules/playintegrityfix/custom.pif.prop`

Betas' validity period appears to have changed.
Prefer using the canary props in 'devices'.


## The files under 'emulator' are for testing purposes and wont work in PIFork as-is
